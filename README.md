# Sunrise and Sunset Map 

This project is an interactive web map that allows users to click anywhere on the world map and retrieve sunrise and sunset times for a selected date.

It uses:
- Leaflet.js for the interactive map
- OpenStreetMap for map tiles
- Sunrise-Sunset API for astronomical data

## How It Works

1. The map loads centered at latitude 20, longitude 0.
2. The user selects a date from a date input field.
3. The user clicks anywhere on the map.
4. A marker is placed at the clicked location.
5. The Sunrise-Sunset API is called with the selected location and date.
6. Sunrise and sunset times are displayed on the page.

---

## Requirements

You need the following:

- A web browser
- Internet connection
- Leaflet.js library
- HTML file with required elements
